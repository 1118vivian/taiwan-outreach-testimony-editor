# 台島展見證稿編輯器

參照同層的主日申言稿編輯器，依據「台島展見證稿.docx」的欄位製作。

## 使用方式

直接以瀏覽器開啟 `index.html`，不需安裝或連線。請保留 `app.js`、`styles.css` 與 `vendor` 資料夾。

1. 填寫分類名稱、組別、姓名與日期。
2. 填寫主題、真理與啟示（30％）、應用與經歷（50％）、結語與願望（20％）。
3. 查看即時 A4 預覽與字數，下載 DOCX 或 PDF。手機可使用「分享 Word」；不支援分享的瀏覽器會改成下載。

分類名稱可自行輸入，亦提供「職事、真理、生命、性格、事奉與心志」選項。內文字數不含空白與主題，範本建議每人約 300～400 字，約 2～3 分鐘。

## 儲存與版面

- 草稿儲存在目前瀏覽器的 localStorage，不會上傳；不同瀏覽器、裝置或網站位址不會共用。清除瀏覽器資料也會移除草稿。
- 「清空」會在確認後清除欄位及草稿。
- DOCX 匯出為原生 Word 文字與表格，可直接修改內容及格式；下載與手機分享均使用可編輯版本。欄位標題置中，正文靠左，應用與經歷保留較大空間。
- 預覽與 PDF 保留固定 A4 版面，超出高度時會縮小。Word 依內容自然換頁，字型與裝置可能造成與預覽略有差異。
- 套件均保留在 vendor，不依賴 CDN。分享功能仍依瀏覽器及作業系統支援。

## 部署與維護

可將本資料夾完整放到靜態網站主機或 GitHub Pages。更新程式或樣式時，請同步更新 index.html 內的版本號。公開網址：https://1118vivian.github.io/taiwan-outreach-testimony-editor/ 。推送 main 分支後會由 GitHub Actions 自動部署。

## 本機驗證

已以桌面及 390px 手機寬度驗證欄位預覽、草稿還原、清空、長文縮放、文字安全顯示、DOCX 下載及 PDF 下載。PDF 已確認為單頁 A4；DOCX 已檢查原生文字與四列表格、空白段落、特殊符號、長文、無內嵌圖片、無編輯保護，以及修改後儲存並重新讀取內容。此環境缺少 Word／LibreOffice，未完成 Word 排版引擎的視覺渲染驗證。
